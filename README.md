# 📰 News App

A simple and responsive **News Application** built using **HTML**, **CSS**, and **JavaScript**.  
It uses the **NewsAPI** to fetch and display the latest news articles from various categories like Technology, Business, Food, Movies, and more.

---

## 🚀 Features

- 🔍 **Search Functionality** — Search for any topic and get real-time news results.  
- 📰 **Dynamic Rendering** — Fetches and displays the latest articles using NewsAPI.  
- 📱 **Responsive Design** — Works smoothly on both desktop and mobile.  
- 📅 **Publication Details** — Displays article source and publication date.  
- 🧭 **Category Navigation** — Quick access to popular categories like *Tech*, *Business*, *Movies*, etc.

---

## 🧩 Tech Stack

- **HTML5** — Structure and layout  
- **CSS3** — Styling and responsiveness  
- **JavaScript (ES6)** — Dynamic content and API integration  
- **NewsAPI.org** — Source of news articles
